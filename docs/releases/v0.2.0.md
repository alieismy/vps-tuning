## 范围与迁移

- 从已验证的 rc.6 实现收敛；保留 17 项受管 sysctl、资源感知缓冲、BBR + fq、managed-state schema 4、checkpoint schema 2、预算及恢复边界，不新增调优功能。
- 必需迁移来源为公开固定 rc.4/rc.5，Debian 12/13 同 profile，配置输入 1–10000 Mbps。冻结 port、RTT、auto/explicit buffer、swap 和代理服务验证意图；两次人工重启后完成严格验证。目标入口在 COMPLETE 后切换。
- 代码保留 rc.6 来源分支；rc.6 未公开且未完成该来源的端到端验证，不作为已验证公开迁移承诺，不要求用户先安装 rc.6。
- Debian 12/13、Ubuntu 24.04 的 x86_64/aarch64 新装范围保持；Ubuntu 迁移未纳入，ARM64 迁移未增加验收承诺。旧 schema 1 checkpoint 继续使用自己的固定工具。
- 新增当前迁移器 CLI 的失败接续验证：来源 rollback 非零（含 state 已退出）、目标 apply 非零/残留 APPLIED 后恢复重试、严格 verify 非零重试、后期退出目标不重新 apply。测试保留真实归档/锁/活动登记，profile 为故障替身、boot ID 为模拟；真实来源、目标 profile 及重启由隔离客体另证。
- 校准工具增加正式 0.2.0 固定 profile 报告版本识别，保持既有历史输入及 adaptive 拒绝边界；独立工具版本不升级。

实施与恢复以[迁移契约](../stable-migration-design.md)及[首台验收方案](../first-host-migration-acceptance.md)为准。目标 rollback 不是自动降级；后期退出后不能手改 checkpoint 重开。正式候选的实机迁移、业务和约定观察仍待完成，公开发布须另行授权。

(
  set -Eeuo pipefail
  cd /absolute/path/to/frozen-bundle
  printf '%s  %s\n' \
    '803b371b754757e054faeadfb08fa3d03036e927a89c3cc2c108fed40c7fcc0b' SHA256SUMS \
