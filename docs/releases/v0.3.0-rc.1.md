# v0.3.0-rc.1 开发候选：Ubuntu 26.04 LTS 新装适配

日期：2026-11-26（Asia/Singapore）。状态：用户已授权实施后继平台适配，本地实现与验证进行中，Linux CI及新平台客体结果待记录。不是公开Release，不得使用不存在的远端下载地址安装。已冻结并实机验收的0.2.0资产不变，本开发分支不改写其证据或部署状态。

## 范围

- 新增 `ubuntu2604-adaptive`，支持原生systemd的Ubuntu26.04 LTS、x86_64/aarch64完整主机；继续复用17项sysctl、BDP与内存封顶、BBR/fq、受管文件所有权和回滚机制，不新增调优策略。4vCPU、4GB和2000Mbps本来就在adaptive输入范围内。
- 控制器、profile、安装器及当前迁移器统一使用0.3.0-rc.1，避免在0.2.0已产生实机state后同号改变运行字节。原公开rc.5与全部历史资产不变。
- 既有Debian固定来源rc.4/rc.5的四组迁移回归随目标版本一起验证；rc.6分支保留为未公开历史来源。**本候选不接受0.2.0受管主机直接迁入，不支持Ubuntu24.04→26.04原地OS升级或Ubuntu跨版本受管状态迁移。** 首台已完成0.2.0验收的AWS主机不参与此次测试。
- 新平台验证复用已有生命周期，初始/重启后的带宽输入为2000Mbps；原平台保留1Mbps下界与10000Mbps重配置检查。无公网测速，不把输入范围称为2Gbps吞吐承诺。

## 镜像与兼容性重点

使用[官方固定镜像目录](https://cloud-images.ubuntu.com/releases/resolute/release-20261108/)的普通amd64及arm64镜像，URL/SHA-256固定在[镜像清单](../../tests/platform-images.json)，不使用mutable current或额外要求amd64v3。镜像manifest已包含测试依赖，26.04客体不安装24.04的deb，也不替换默认coreutils供应者。

检查Linux7.0的17项sysctl和mq/fq恢复、systemd启动持久性及NOFILE、安装/权限/摘要/原子切换与回滚。客体证据包含软件包版本与实际systemctl、stat、readlink、install、chmod、chown、sha256sum、cp、mv版本。ARM64保留TCG指针认证快速实现，仅作功能证据，不宣称硬件性能。
